🌍 DATAWISE — India Air Quality Intelligence

An interactive Data Science dashboard for exploring, analyzing, and visualizing air-quality datasets using Python and Streamlit.

🚀 Live Demo

Live App: https://datawise-india-air-quality-analysis-e5kjusruhpuermyxtvoatx.streamlit.app/

📌 Project Overview

DATAWISE helps users understand air-quality data through interactive visualizations and dataset analysis. Upload a CSV file to explore pollution measurements, identify missing values, examine distributions, and download cleaned data.

✨ Features

- 📂 Upload air-quality datasets in CSV format
- 👀 Preview uploaded data
- 📊 View dataset statistics, including rows and columns
- 🔍 Analyze missing values in each column
- 📈 Generate interactive histograms
- 🔗 Explore relationships between numerical variables using scatter plots
- 📥 Download a cleaned dataset

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

⚙️ Installation and Setup

1. Clone this repository:
   
   git clone https://github.com/25eg107e19-arch/datawise-india-air-quality-analysis.git

2. Open the project folder:
   
   cd datawise-india-air-quality-analysis

3. Install the required libraries:
   
   pip install -r requirements.txt

4. Run the application:
   
   streamlit run app.py

📊 How to Use

1. Open the live application.
2. Upload an air-quality dataset in CSV format.
3. Explore the dataset preview and missing-value report.
4. Select numerical columns to visualize distributions and relationships.
5. Download the cleaned dataset for further analysis.

🎯 Learning Outcomes

- Data loading and preprocessing with Pandas
- Exploratory Data Analysis (EDA)
- Interactive data visualization
- Handling missing values
- Building and deploying a Streamlit application

⚠️ Limitations

The dashboard analyzes the CSV file supplied by the user. Results depend on the dataset's contents, column types, and data quality. It does not currently provide live pollution readings or air-quality forecasts.
